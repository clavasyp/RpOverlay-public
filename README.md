# RpOverlay

Десктоп-клиент [TurgovBot](https://t.me/turgovovka) для Windows: оверлей поверх игры
для ролевых GTA5-проектов. Голосовые вопросы по законам сервера, подсказки в ролях
адвоката и прокурора, поиск статей, помощь на «обзвоне» лидерки. Окна можно спрятать
от захвата экрана и OBS.

Клиент работает с API TurgovBot: вход через Telegram-бота, доступ по подписке,
тестер-статусу или лицензионному ключу.

## Возможности

- **Вопросы голосом и текстом** по законодательной базе выбранного сервера.
- **Режимы ролей:** адвокат, прокурор, общий. Оверлей может слушать сцену и сам
  предлагать ответ.
- **Поиск статей** с избранным — отдельная вкладка хаба.
- **Локальное распознавание речи и разделение говорящих** на ПК (sherpa-onnx),
  модели докачиваются по кнопке.
- **Невидимость для захвата:** окна и всплывающие подсказки исключаются из записи экрана.
- **Автообновление** по подписанному манифесту (Ed25519) с заменой только изменённых файлов.
- **Резервный канал связи**, если основной домен недоступен.

## Сборка

Нужны Windows, CMake 3.21+, Qt 6 под MinGW (Core, Gui, Widgets, Network,
WebSockets), OpenSSL и MSYS2 UCRT64 для рантайм-библиотек. Стандарт C++17.

```bash
cmake -S . -B build -G Ninja -DCMAKE_PREFIX_PATH=<путь к Qt6>
cmake --build build
bash build-dist.sh        # собрать dist/ со всеми DLL рядом с exe
```

Варианты сборки:

| Опция CMake | Что получится |
|---|---|
| по умолчанию | полная сборка, все режимы |
| `-DRPOVERLAY_QA=ON` | публичный вариант только с вопросами |
| `-DRPOVERLAY_LAWS=ON` | только поиск по законам |

Локальное распознавание речи включается, если в `thirdparty/` лежит готовая сборка
`sherpa-onnx-v1.13.2-win-x64-shared-MD-Release-no-tts`. Без неё клиент собирается
без локального распознавания.

Установщик собирается Inno Setup по `RpOverlay.iss`.

## Конфигурация

Адреса сервера зашиты в `src/Config.cpp`. Для разработки их можно переопределить
файлом `config.json` рядом с exe (пример — `config.example.json`): поля `apiBaseUrl`,
`wsBaseUrl`, `serverId`, `botUsername`, `relayApiBaseUrl`, `relayWsBaseUrl`.

Пользовательские настройки (микрофон, окно, хоткеи) живут в
`%APPDATA%\RpOverlay\settings.json`.

## Что убрано из публичной версии

- Адрес и сертификат резервного RU-релея: в `src/Config.cpp` вместо него стоит
  `relay.invalid`, `src/relay_cert.h` пуст. Чтобы подключить свой релей, задайте
  `relayApiBaseUrl`/`relayWsBaseUrl` в `config.json` и положите его сертификат
  в `src/relay_cert.h`.
- Релизные скрипты заливки на сервер и профили защиты Themida.
